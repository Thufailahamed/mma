# MMA Platform — Phase 1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a running monorepo with a Next.js frontend and a Hono API on Cloudflare Workers, backed by a complete 42-table D1 schema, working email/password authentication, a premium design system, and a homepage shell rendering designed empty states.

**Architecture:** Three deployable units — `apps/web` (Next.js 15 via `@opennextjs/cloudflare`), `apps/api` (Hono Worker), `workers/realtime` (Durable Objects). Three source-only packages: `@mma/db` (Drizzle schema), `@mma/validation` (Zod, imported by both client and server), `@mma/shared` (types, envelope, scoring rules). The browser talks only to the Next origin; a Next rewrite proxies `/api/*` to the Worker, so session cookies are same-origin in development and production and CORS is never configured.

**Tech Stack:** Next.js 15 · React 19 · TypeScript 5.7 strict · Tailwind CSS v4 · shadcn/ui · Framer Motion · Lucide · Hono · Drizzle ORM + drizzle-kit · Cloudflare Workers / D1 / R2 / Durable Objects · Zod · Vitest · Playwright · pnpm workspaces

**Design spec:** `docs/superpowers/specs/2026-09-28-mma-platform-phase-1-design.md`

## Global Constraints

These apply to every task. Do not deviate without updating the spec.

- **Node ≥ 22.11**, **pnpm 11**, **Wrangler 4**, pinned via the root `packageManager` field.
- **TypeScript `strict` plus `noUncheckedIndexedAccess: true`.** Array access returns `T | undefined`; an unchecked access is a compile error. This is what makes the spec's rule 7 real.
- **D1 timestamps are `INTEGER` unix epoch milliseconds**, drizzle `mode: 'timestamp_ms'`.
- **D1 primary keys are `TEXT`** holding `crypto.randomUUID()`.
- **Enums are `TEXT` plus a `CHECK (col IN (...))` constraint**, enforced by D1 and not only by TypeScript.
- **Booleans are `INTEGER` 0/1**, drizzle `mode: 'boolean'`.
- **Every foreign key column gets an explicit index.** D1 does not create them automatically.
- **Migrations are generated by drizzle-kit into `database/migrations/` and applied with `wrangler d1 migrations apply`.** Never edit an applied migration. Never run `drizzle-kit push` against D1.
- **Layer separation is one-directional:** `routes` (HTTP) → `services` (business logic) → repositories in `@mma/db` (SQL). SQL appears nowhere except `packages/db`. Business logic appears nowhere in React components.
- **Every `c.req.json()` passes through a Zod `safeParse` from `@mma/validation`.** No unvalidated value reaches a query.
- **Response envelope is always** `{ success: true, data }` or `{ success: false, error: { code, message, details?, requestId } }`.
- **No route, button, or component may pretend to do Phase 2+ work.** Stubs are prohibited; a dimmed, honestly-labelled control is acceptable.
- **R2 object keys are never exposed as raw URLs.** All media goes through `GET /img/:key`.
- **Framer Motion never appears in a Server Component.** It enters only at named `"use client"` leaves.
- **Every motion effect respects `prefers-reduced-motion`** and animates only `transform` and `opacity`.
- **`@mma/db` must never be imported from `apps/web/components` or `apps/web/hooks`.** Enforced by an ESLint `no-restricted-imports` rule from Task 1.
- **No string-interpolated SQL outside `packages/db`.** Enforced by an ESLint `no-restricted-syntax` rule from Task 1.
- **Commit after every task.** Conventional Commits, lowercase, imperative subject under 72 characters.

**Responsibility boundaries:**

- `packages/db/src/schema/*.ts` — table definitions only, grouped by domain. No queries, no business logic.
- `packages/db/src/client.ts` — creates the Drizzle instance from a D1 binding. The single place `D1Database` is referenced.
- `packages/db/src/repositories/*.ts` — the only files containing SQL or Drizzle query builders.
- `apps/api/src/services/*.ts` — all business logic and all row-level authorization. Receives validated typed input; never touches `c`.
- `apps/api/src/routes/*.ts` — parse, delegate to one service, format. No SQL, no branching business rules.
- `apps/api/src/middleware/*.ts` — one file per middleware, each exporting a single Hono middleware factory.
- `apps/web/lib/api.ts` — the single fetch path for the browser.
- `apps/web/components/ui/*` — shadcn-generated, unmodified upstream.
- `apps/web/components/mma/*` — domain components, one component per file.

- [ ] **Step 4: Write the identity and access tables**

`packages/db/src/schema/identity.ts`:

```ts
import { sql } from 'drizzle-orm'
import { check, index, integer, sqliteTable, text, uniqueIndex } from 'drizzle-orm/sqlite-core'
import { USER_ROLES } from './enums'

const createdAt = integer('created_at', { mode: 'timestamp_ms' })
  .notNull().default(sql`(unixepoch() * 1000)`)
const updatedAt = integer('updated_at', { mode: 'timestamp_ms' })
  .notNull().default(sql`(unixepoch() * 1000)`)

export const users = sqliteTable('users', {
  id: text('id').primaryKey(),
  email: text('email').notNull(),
  username: text('username').notNull(),
  displayName: text('display_name').notNull(),
  passwordHash: text('password_hash').notNull(),
  avatarUrl: text('avatar_url'),
  role: text('role', { enum: USER_ROLES }).notNull().default('USER'),
  xp: integer('xp').notNull().default(0),
  level: integer('level').notNull().default(1),
  createdAt,
  updatedAt,
}, (t) => [
  uniqueIndex('users_email_unique').on(t.email),
  uniqueIndex('users_username_unique').on(t.username),
  check('users_role_check', sql`${t.role} IN ('USER','EDITOR','ADMIN')`),
  check('users_xp_non_negative', sql`${t.xp} >= 0`),
  check('users_level_positive', sql`${t.level} >= 1`),
])

export const userProfiles = sqliteTable('user_profiles', {
  id: text('id').primaryKey(),
  userId: text('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  bio: text('bio'),
  country: text('country'),
  favoriteFighterId: text('favorite_fighter_id'),
  predictionAccuracy: integer('prediction_accuracy').notNull().default(0),
  totalPredictions: integer('total_predictions').notNull().default(0),
  correctPredictions: integer('correct_predictions').notNull().default(0),
  triviaXp: integer('trivia_xp').notNull().default(0),
  predictionPoints: integer('prediction_points').notNull().default(0),
  currentStreak: integer('current_streak').notNull().default(0),
  longestStreak: integer('longest_streak').notNull().default(0),
  createdAt,
  updatedAt,
}, (t) => [
  uniqueIndex('user_profiles_user_unique').on(t.userId),
  index('user_profiles_favorite_fighter_idx').on(t.favoriteFighterId),
  check('user_profiles_accuracy_range', sql`${t.predictionAccuracy} BETWEEN 0 AND 100`),
  check('user_profiles_correct_le_total', sql`${t.correctPredictions} <= ${t.totalPredictions}`),
])

export const sessions = sqliteTable('sessions', {
  id: text('id').primaryKey(),
  userId: text('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  tokenHash: text('token_hash').notNull(),
  expiresAt: integer('expires_at', { mode: 'timestamp_ms' }).notNull(),
  userAgent: text('user_agent'),
  ip: text('ip'),
  createdAt,
}, (t) => [
  uniqueIndex('sessions_token_hash_unique').on(t.tokenHash),
  index('sessions_user_idx').on(t.userId),
  index('sessions_expires_at_idx').on(t.expiresAt),
])

export const xpEvents = sqliteTable('xp_events', {
  id: text('id').primaryKey(),
  userId: text('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  source: text('source').notNull(),
  amount: integer('amount').notNull(),
  referenceId: text('reference_id'),
  createdAt,
}, (t) => [
  index('xp_events_user_created_idx').on(t.userId, t.createdAt),
  index('xp_events_source_idx').on(t.source),
])

export const auditLogs = sqliteTable('audit_logs', {
  id: text('id').primaryKey(),
```

`workers/realtime/src/rate-limiter.ts`:

```ts
export interface RateLimitRequestBody {
  key: string
  limit: number
  windowMs: number
}

export interface RateLimitResult {
  allowed: boolean
  retryAfterSeconds: number
  remaining: number
}

export class RateLimiter {
  constructor(private readonly state: DurableObjectState) {}

  async fetch(request: Request): Promise<Response> {
    const body = (await request.json()) as RateLimitRequestBody
    const now = Date.now()

    const stored = await this.state.storage.get<{ count: number; resetAt: number }>('window')
    const windowIsActive = stored !== undefined && now < stored.resetAt
    const count = (windowIsActive ? stored.count : 0) + 1
    const resetAt = windowIsActive ? stored.resetAt : now + body.windowMs

    await this.state.storage.put('window', { count, resetAt })

    const result: RateLimitResult = {
      allowed: count <= body.limit,
      retryAfterSeconds: Math.max(0, Math.ceil((resetAt - now) / 1000)),
      remaining: Math.max(0, body.limit - count),
    }

    return Response.json(result)
  }
}
```

```ts
import type { MiddlewareHandler } from 'hono'
import type { RateLimitResult } from './rate-limiter'

export interface RateLimiterBinding {
  RATE_LIMITER: DurableObjectNamespace
}

export interface RateLimitOptions {
  limit: number
  windowMs: number
  /**
   * Return a stable per-caller key. This runs before authentication, so it must
   * not depend on ctx.user.
   */
  key: (c: { req: Request; env: RateLimiterBinding }) => string | Promise<string>
}

export function ratelimit(options: RateLimitOptions): MiddlewareHandler<RateLimiterBinding> {
  return async (c, next) => {
    const key = await options.key(c)
    const stubId = fnv1a(key)
    const id = c.env.RATE_LIMITER.idFromName(stubId)

    const response = await c.env.RATE_LIMITER.get(id).fetch('https://ratelimiter.internal', {
      method: 'POST',
      body: JSON.stringify({ key, limit: options.limit, windowMs: options.windowMs }),
    })
    const verdict = (await response.json()) as RateLimitResult

    c.header('X-RateLimit-Limit', String(options.limit))
    c.header('X-RateLimit-Remaining', String(verdict.remaining))

    if (!verdict.allowed) {
      c.header('Retry-After', String(verdict.retryAfterSeconds))
      return c.json(
        {
          success: false,
          error: { code: 'RATE_LIMITED', message: 'Too many requests. Please slow down.' },
        },
        429,
      )
    }

    await next()
  }
}

/** FNV-1a: maps a key string to a stable Durable Object stub name. */
function fnv1a(value: string): string {
  let hash = 2166136261
  for (let index = 0; index < value.length; index += 1) {
    hash ^= value.charCodeAt(index)
    hash = Math.imul(hash, 16777619)
  }
  return (hash >>> 0).toString(36)
}
```

```ts
import type { ErrorCode, FieldIssue } from './envelope'

type ConflictCode = Extract<ErrorCode, 'CONFLICT' | 'PREDICTION_LOCKED' | 'SCORING_WINDOW_CLOSED'>
type AppErrorStatus = 400 | 401 | 403 | 404 | 409 | 429 | 500

export class AppError extends Error {
  readonly code: ErrorCode
  readonly status: AppErrorStatus
  readonly details?: FieldIssue[]

  constructor(code: ErrorCode, status: AppErrorStatus, message: string, details?: FieldIssue[]) {
    super(message)
    this.name = 'AppError'
    this.code = code
    this.status = status
    if (details !== undefined) this.details = details
  }

  static validation(message: string, details: FieldIssue[]): AppError {
    return new AppError('VALIDATION_ERROR', 400, message, details)
  }

  static unauthenticated(message = 'Authentication required.'): AppError {
    return new AppError('UNAUTHENTICATED', 401, message)
  }

  static forbidden(message = 'You do not have access to this resource.'): AppError {
    return new AppError('FORBIDDEN', 403, message)
  }

  static notFound(message = 'Resource not found.'): AppError {
    return new AppError('NOT_FOUND', 404, message)
  }

  static conflict(code: ConflictCode, message: string): AppError {
    return new AppError(code, 409, message)
  }

  static rateLimited(message = 'Too many requests. Please slow down.'): AppError {
    return new AppError('RATE_LIMITED', 429, message)
  }
}
```

```ts
export function ok<T>(data: T, status: OkStatus = 200): Response {
  if (status === 204) return new Response(null, { status })
  return Response.json({ success: true, data } satisfies ApiSuccess<T>, { status })

export function fail(error: AppError, requestId: string): Response {
  const body: ApiFailure = {
    success: false,
    error: {
      code: error.code,
      message: error.message,
      ...(error.details ? { details: error.details } : {}),
      requestId,
    },
  }
  return Response.json(body, { status: error.status })
}
```

```ts
const BASE64 = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/'
const BASE64URL = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_'

function encode(bytes: Uint8Array, alphabet: string): string {
  let output = ''
  for (let index = 0; index < bytes.length; index += 3) {
    const byteA = bytes[index]!
    const byteB = bytes[index + 1]
    const byteC = bytes[index + 2]
    output += alphabet[byteA >> 2]
    output += alphabet[((byteA & 0x03) << 4) | ((byteB ?? 0) >> 4)]
    output += byteB === undefined ? '=' : alphabet[((byteB & 0x0f) << 2) | ((byteC ?? 0) >> 6)]
    output += byteC === undefined ? '=' : alphabet[byteC & 0x3f]
  }
  return output
}

function decode(value: string, alphabet: string): Uint8Array {
  const clean = value.replace(/=+$/, '')
  const bytes: number[] = []
  for (let index = 0; index < clean.length; index += 4) {
    const chunk = [0, 1, 2, 3].map((offset) => {
      const char = clean[index + offset]
      return char === undefined ? 0 : alphabet.indexOf(char)
    })
    const [a, b, c, d] = chunk as [number, number, number, number]
    bytes.push((a << 2) | (b >> 4))
    if (clean.length > index + 2) bytes.push(((b & 0x0f) << 4) | (c >> 2))
    if (clean.length > index + 3) bytes.push(((c & 0x03) << 6) | d)
  }
  return new Uint8Array(bytes)
}

export function base64Encode(bytes: Uint8Array): string {
  return encode(bytes, BASE64)
}

export function base64Decode(value: string): Uint8Array {
  return decode(value, BASE64)
}

export function base64UrlEncode(bytes: Uint8Array): string {
  return encode(bytes, BASE64URL)
}

export function base64UrlDecode(value: string): Uint8Array {
  return decode(value, BASE64URL)
}

/**
 * Constant-time comparison over a fixed-length XOR accumulator. Returns false
 * immediately on a length mismatch, because the length of a derived key is
 * never secret.
 */
export function timingSafeEqual(a: Uint8Array, b: Uint8Array): boolean {
  if (a.length !== b.length) return false
  let difference = 0
  for (let index = 0; index < a.length; index += 1) {
    difference |= a[index]! ^ b[index]!
  }
  return difference === 0
}
```

`apps/api/src/crypto/password.ts`:

```ts
import { base64Decode, base64Encode, timingSafeEqual } from './encoding'

export const PASSWORD_ALGORITHM = 'pbkdf2_sha256'
/** OWASP's current floor for PBKDF2-SHA256. */
export const PBKDF2_ITERATIONS = 310_000
const KEY_BYTES = 32
const SALT_BYTES = 16

async function derive(password: string, salt: Uint8Array, iterations: number): Promise<Uint8Array> {
  const keyMaterial = await crypto.subtle.importKey(
    'raw',
    new TextEncoder().encode(password),
    'PBKDF2',
    false,
    ['deriveBits'],
  )
  const bits = await crypto.subtle.deriveBits(
    { name: 'PBKDF2', salt, iterations, hash: 'SHA-256' },
    keyMaterial,
    KEY_BYTES * 8,
  )
  return new Uint8Array(bits)
}

function parse(stored: string): { salt: Uint8Array; hash: Uint8Array; iterations: number } | null {
  const parts = stored.split('$')
  if (parts.length !== 4) return null
  const [algorithm, rawIterations, rawSalt, rawHash] = parts as [string, string, string, string]
  if (algorithm !== PASSWORD_ALGORITHM) return null

  const iterations = Number.parseInt(rawIterations, 10)
  if (!Number.isSafeInteger(iterations) || iterations < 1) return null

  try {
    return { salt: base64Decode(rawSalt), hash: base64Decode(rawHash), iterations }
  } catch {
    return null
  }
}

export async function hashPassword(password: string, iterations = PBKDF2_ITERATIONS): Promise<string> {
  const salt = crypto.getRandomValues(new Uint8Array(SALT_BYTES))
  const hash = await derive(password, salt, iterations)
  return `${PASSWORD_ALGORITHM}$${iterations}$${base64Encode(salt)}$${base64Encode(hash)}`
}

export async function verifyPassword(password: string, stored: string): Promise<boolean> {
  const parsed = parse(stored)
  if (parsed === null) return false
  if (parsed.salt.length !== SALT_BYTES || parsed.hash.length !== KEY_BYTES) return false
  const candidate = await derive(password, parsed.salt, parsed.iterations)
  return timingSafeEqual(candidate, parsed.hash)
}

export function needsRehash(stored: string): boolean {
  const parsed = parse(stored)
  return parsed === null || parsed.iterations < PBKDF2_ITERATIONS
}
```

```ts
import type { Db } from '@mma/db'
import { createSessionsRepo } from '@mma/db/repositories'
import type { SessionUser } from '../env'
import { base64UrlEncode, timingSafeEqual } from '../crypto/encoding'
import { generateSessionToken, hashToken } from '../crypto/token'

export const SESSION_COOKIE = 'mma_session'
export const CSRF_COOKIE = 'mma_csrf'
export const SESSION_TTL_MS = 30 * 24 * 60 * 60 * 1000

export interface SessionMeta {
  userAgent?: string
  ip?: string
}

export function cookieOptions(expiresAt: Date): string {
  return [
    'Path=/',
    'HttpOnly',
    'Secure',
    'SameSite=Lax',
    `Expires=${expiresAt.toUTCString()}`,
  ].join('; ')
}

export function csrfCookieOptions(expiresAt: Date): string {
  return ['Path=/', 'Secure', 'SameSite=Lax', `Expires=${expiresAt.toUTCString()}`].join('; ')
}

export async function createSession(
  db: Db,
  userId: string,
  meta: SessionMeta = {},
): Promise<{ token: string; csrfToken: string; expiresAt: Date }> {
  const token = await generateSessionToken()
  const csrfToken = base64UrlEncode(crypto.getRandomValues(new Uint8Array(24)))
  const expiresAt = new Date(Date.now() + SESSION_TTL_MS)

  await createSessionsRepo(db).insert({
    id: crypto.randomUUID(),
    userId,
    tokenHash: await hashToken(token),
    expiresAt,
    ...meta,
  })

  return { token, csrfToken, expiresAt }
}

export async function resolveSession(db: Db, token: string): Promise<SessionUser | null> {
  const repo = createSessionsRepo(db)
  const row = await repo.findByTokenHash(await hashToken(token))
  if (row === undefined || row.expiresAt.getTime() <= Date.now()) {
    if (row !== undefined) await repo.deleteById(row.id)
    return null
  }

  const nextExpiry = new Date(Date.now() + SESSION_TTL_MS)
  await repo.touchExpiry(row.id, nextExpiry)

  const user = await createUsersRepo(db).findById(row.userId)
  if (user === undefined) return null

  return {
    id: user.id,
    email: user.email,
    username: user.username,
    displayName: user.displayName,
    role: user.role,
    sessionId: row.id,
  }
}

export async function revokeSession(db: Db, sessionId: string): Promise<void> {
  await createSessionsRepo(db).deleteById(sessionId)
}

export function cookiesEqual(a: string, b: string): boolean {
  return timingSafeEqual(new TextEncoder().encode(a), new TextEncoder().encode(b))
}
```

```ts
import { AppError, XP_REWARDS, levelForXp } from '@mma/shared'
import type { LoginInput, RegisterInput } from '@mma/validation'
import { hashPassword, needsRehash, verifyPassword } from '../crypto/password'
import type { SessionUser } from '../env'
import type { SessionsRepo, UsersRepo } from '@mma/db/repositories'

/** The generic message used for every failed login, so the API never reveals which field was wrong. */
const INVALID_CREDENTIALS = 'Email or password is incorrect.'

export interface AuthDeps {
  users: UsersRepo
  sessions: SessionsRepo
  xp: Pick<UsersRepo, 'addXpEvent' | 'incrementXp'>
}

export function buildAuthService(deps: AuthDeps) {
  return {
    async register(input: RegisterInput): Promise<SessionUser> {
      const [existingEmail, existingUsername] = await Promise.all([
        deps.users.findByEmail(input.email),
        deps.users.findByUsername(input.username),
      ])
      if (existingEmail !== undefined || existingUsername !== undefined) {
        throw new AppError('CONFLICT', 409, 'That email or username is already registered.')
      }

      const id = crypto.randomUUID()
      const row = await deps.users.insertUser({
        id,
        email: input.email,
        username: input.username,
        displayName: input.displayName,
        passwordHash: await hashPassword(input.password),
        role: 'USER',
      })
      if (row === undefined) throw new AppError('INTERNAL_ERROR', 500, 'Could not create the account.')

      await deps.xp.addXpEvent({
        id: crypto.randomUUID(),
        userId: id,
        source: 'registration',
        amount: XP_REWARDS.registration,
      })
      await deps.xp.incrementXp(id, XP_REWARDS.registration, levelForXp(XP_REWARDS.registration))

      return {
        id: row.id,
        email: row.email,
        username: row.username,
        displayName: row.displayName,
        role: row.role,
        sessionId: '',
      }
    },

    async login(input: LoginInput): Promise<SessionUser> {
      const user = await deps.users.findByEmail(input.email)
      if (user === undefined) {
        // Derive once against a dummy hash so a missing account and a wrong
        // password take comparable time and cannot be told apart by timing.
        await verifyPassword(input.password, 'pbkdf2_sha256$310000$AAAAAAAAAAAAAAAAAAAAAA==$AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=')
        throw AppError.unauthenticated(INVALID_CREDENTIALS)
      }
      if (!(await verifyPassword(input.password, user.passwordHash))) {
        throw AppError.unauthenticated(INVALID_CREDENTIALS)
      }
      if (needsRehash(user.passwordHash)) {
        await deps.users.updatePasswordHash(user.id, await hashPassword(input.password))
      }
      return {
        id: user.id,
        email: user.email,
        username: user.username,
        displayName: user.displayName,
        role: user.role,
        sessionId: '',
      }
    },
  }
}
```

```ts
export function readCookie(request: Request, name: string): string | undefined {
  const header = request.headers.get('cookie')
  if (header === null) return undefined
  for (const part of header.split(';')) {
    const separator = part.indexOf('=')
    if (separator === -1) continue
    if (part.slice(0, separator).trim() === name) {
      return decodeURIComponent(part.slice(separator + 1).trim())
    }
  }
  return undefined
}
```

```ts
import type { MiddlewareHandler } from 'hono'
import { AppError } from '@mma/shared'
import { readCookie } from './cookies'
import { CSRF_COOKIE } from '../services/session-service'

const SAFE_METHODS = new Set(['GET', 'HEAD', 'OPTIONS'])

export function csrf(): MiddlewareHandler {
  return async (c, next) => {
    if (SAFE_METHODS.has(c.req.method)) {
      await next()
      return
    }
    const cookie = readCookie(c.req.raw, CSRF_COOKIE)
    const header = c.req.header('x-csrf-token')
    if (cookie === undefined || header === undefined || cookie !== header) {
      throw new AppError('CSRF_TOKEN_INVALID', 403, 'CSRF token missing or invalid.')
    }
    await next()
  }
}
```

```ts
    const parsed = registerSchema.safeParse(await c.req.json())
    if (!parsed.success) {
      return fail(
        AppError.validation('Request body failed validation.', toFieldIssues(parsed.error)),
        c.get('requestId'),
      )
    }

    const db = createDb(c.env)
    const users = createUsersRepo(db)
    const auth = buildAuthService({ users, sessions: createSessionsRepo(db), xp: users })

    const created = await auth.register(parsed.data)
    const { token, csrfToken, expiresAt } = await createSession(db, created.id, {
      userAgent: c.req.header('user-agent') ?? undefined,
      ip: c.req.header('cf-connecting-ip') ?? undefined,
    })

    c.header('Set-Cookie', `${SESSION_COOKIE}=${token}; ${cookieOptions(expiresAt)}`)
    c.header('Set-Cookie', `${CSRF_COOKIE}=${csrfToken}; ${csrfCookieOptions(expiresAt)}`)
    return ok(publicShape({ ...created, sessionId: '' }), 201)
  })

  routes.post('/login', async (c) => {
    const parsed = loginSchema.safeParse(await c.req.json())
    if (!parsed.success) {
      return fail(
        AppError.validation('Request body failed validation.', toFieldIssues(parsed.error)),
        c.get('requestId'),
      )
    }

    const db = createDb(c.env)
    const users = createUsersRepo(db)
    const auth = buildAuthService({ users, sessions: createSessionsRepo(db), xp: users })

    const user = await auth.login(parsed.data)
    const { token, csrfToken, expiresAt } = await createSession(db, user.id, {
      userAgent: c.req.header('user-agent') ?? undefined,
      ip: c.req.header('cf-connecting-ip') ?? undefined,
    })

    c.header('Set-Cookie', `${SESSION_COOKIE}=${token}; ${cookieOptions(expiresAt)}`)
    c.header('Set-Cookie', `${CSRF_COOKIE}=${csrfToken}; ${csrfCookieOptions(expiresAt)}`)
    return ok(publicShape({ ...user, sessionId: '' }))
  })

  routes.post('/logout', requireAuth(), async (c) => {
    await revokeSession(createDb(c.env), c.get('user').sessionId)
    c.header('Set-Cookie', `${SESSION_COOKIE}=; ${cookieOptions(new Date(0))}`)
    c.header('Set-Cookie', `${CSRF_COOKIE}=; ${csrfCookieOptions(new Date(0))}`)
    return ok({ signedOut: true })
  })

  routes.get('/me', requireAuth(), async (c) => {
    const user = c.get('user')
    const profile = await createUsersRepo(createDb(c.env)).findProfile(user.id)
    return ok({ ...publicShape(user), profile: profile ?? null })
  })

  return routes
}
```

```ts
import { createDb } from '@mma/db'
import { eq } from 'drizzle-orm'
import { Hono } from 'hono'
import { AppError } from '@mma/shared'
import { imageQuerySchema, toFieldIssues } from '@mma/validation'
import { mediaAssets } from '@mma/db/schema'
import type { Env } from '../env'

const ALLOWED_WIDTHS = new Set([64, 128, 256, 384, 512, 768, 1024, 1536, 2048])
const CACHE_CONTROL = 'public, max-age=31536000, immutable'

export function createMediaRoutes() {
  const routes = new Hono<{ Bindings: Env }>()

  routes.get('/:key{.+}', async (c) => {
    const key = c.req.param('key')
    if (key.includes('..')) throw AppError.notFound('No such asset.')

    const parsed = imageQuerySchema.safeParse(c.req.query())
    if (!parsed.success) {
      throw AppError.validation('Invalid image parameters.', toFieldIssues(parsed.error))
    }
    const { w, f, q } = parsed.data
    if (w !== undefined && !ALLOWED_WIDTHS.has(w)) {
      throw AppError.validation('Unsupported width.', [{ path: 'w', message: 'Use an allow-listed width.' }])
    }

    const asset = await createDb(c.env)
      .select()
      .from(mediaAssets)
      .where(eq(mediaAssets.objectKey, key))
      .get()
    if (asset === undefined) throw AppError.notFound('No such asset.')

    const object = await c.env.MEDIA.get(key, {
      onlyIf: { etag: asset.objectKey },
      ...(w === undefined ? {} : {
        cf: {
          image: {
            width: w,
            ...(f === undefined ? {} : { format: f }),
            ...(q === undefined ? {} : { quality: q }),
          },
        },
      }),
    })
    if (object === null) throw AppError.notFound('No such asset.')

    return new Response(object.body, {
      headers: {
        'Content-Type': object.httpMetadata?.contentType ?? asset.contentType,
        'Cache-Control': CACHE_CONTROL,
        ETag: `"${asset.objectKey}"`,
      },
    })
  })

  return routes
}
```

```ts
const ALLOWED_WIDTHS = new Set([64, 128, 256, 384, 512, 768, 1024, 1536, 2048])

export default function mmaImageLoader({ src, width, quality }: ImageLoaderProps): string {
  if (src.startsWith('http')) return src
  const safeWidth = ALLOWED_WIDTHS.has(width) ? width : 1024
  const params = new URLSearchParams({ w: String(safeWidth), f: 'auto' })
  if (quality !== undefined) params.set('q', String(quality))
```

```tsx
'use client'

import { useEffect, useState } from 'react'
import { cn } from '@/lib/utils'

function remaining(target: number): number {
  return Math.max(0, target - Date.now())
}

function format(ms: number): string {
  const total = Math.floor(ms / 1000)
  const days = Math.floor(total / 86400)
  const hours = Math.floor((total % 86400) / 3600)
  const minutes = Math.floor((total % 3600) / 60)
  const seconds = total % 60
  const pad = (value: number) => String(value).padStart(2, '0')
  return days > 0 ? `${days}d ${pad(hours)}:${pad(minutes)}:${pad(seconds)}` : `${pad(hours)}:${pad(minutes)}:${pad(seconds)}`
}

export interface CountdownProps {
  target: string
  className?: string
}

export function Countdown({ target, className }: CountdownProps) {
  const deadline = new Date(target).getTime()
  const [ms, setMs] = useState(() => remaining(deadline))

  useEffect(() => {
    const timer = setInterval(() => setMs(remaining(deadline)), 1000)
    return () => clearInterval(timer)
  }, [deadline])

  return (
    <time dateTime={target} className={cn('tabular font-mono text-lg', className)} suppressHydrationWarning>
      {format(ms)}
    </time>
  )
}
```

```tsx
  durationMs?: number
  className?: string
}

export function CountUp({ value, durationMs = 600, className }: CountUpProps) {
  const reduce = useReducedMotion()
  const [display, setDisplay] = useState(reduce ? value : 0)

  useEffect(() => {
    if (reduce) {
      setDisplay(value)
      return
    }
    const controls = animate(0, value, {
      duration: durationMs / 1000,
      ease: 'easeOut',
      onUpdate: (latest) => setDisplay(Math.round(latest)),
    })
    return () => controls.stop()
  }, [value, durationMs, reduce])

  return (
    <span className={className} suppressHydrationWarning>
      {display}
    </span>
  )
}
```

```ts
import type { ApiFailure, ApiSuccess, ErrorCode, FieldIssue } from '@mma/shared'

const SAFE_METHODS = new Set(['GET', 'HEAD', 'OPTIONS'])

export class ApiError extends Error {
  readonly code: ErrorCode
  readonly status: number
  readonly details: FieldIssue[]

  constructor(code: ErrorCode, status: number, message: string, details: FieldIssue[] = []) {
    super(message)
    this.name = 'ApiError'
    this.code = code
    this.status = status
    this.details = details
  }
}

export function readCsrfToken(): string | null {
  if (typeof document === 'undefined') return null
  for (const part of document.cookie.split(';')) {
    const [name, ...rest] = part.trim().split('=')
    if (name === 'mma_csrf') return decodeURIComponent(rest.join('='))
  }
  return null
}

/**
 * The single fetch path for the browser. Every request goes through here, so
 * the CSRF header, the error shape, and cache headers cannot be forgotten at
 * a call site.
 */
export async function apiRequest<T>(path: string, init: RequestInit = {}): Promise<T> {
  const method = (init.method ?? 'GET').toUpperCase()
  const headers = new Headers(init.headers)

  if (!SAFE_METHODS.has(method)) {
    headers.set('content-type', 'application/json')
    const token = readCsrfToken()
    if (token !== null) headers.set('x-csrf-token', token)
  }

  const response = await fetch(path, { ...init, headers, credentials: 'same-origin' })
  const payload = (await response.json()) as ApiSuccess<T> | ApiFailure

  if (!response.ok || !payload.success) {
    const error = (payload as ApiFailure).error
    throw new ApiError(
      error?.code ?? 'INTERNAL_ERROR',
      response.status,
      error?.message ?? 'Request failed.',
      error?.details ?? [],
    )
  }

  return (payload as ApiSuccess<T>).data
}

export const apiGet = <T,>(path: string) => apiRequest<T>(path)
export const apiPost = <T,>(path: string, body: unknown) =>
  apiRequest<T>(path, { method: 'POST', body: JSON.stringify(body) })
export const apiLogout = () => apiPost<{ signedOut: boolean }>('/api/auth/logout', {})
```

`apiGet` and `apiPost` are used from client components only. Server Components call `apiRequest` directly during render so React can stream and cache the fetch.
